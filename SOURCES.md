# Sources catalog

**296 open conflict / OSINT sources** for situational awareness — public datasets, feeds, trackers and tools. Generated from `conflictwatch/data/sources.json` (`conflictwatch sources` to query). Respect each provider's terms and rate limits.

`88` expose an RSS/Atom feed (drive the scraper with `conflictwatch scrape`). Access: **open** = no key · **registration** = free account · **paid** = subscription.
